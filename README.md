# Privacy Budget

A privacy-first personal finance app for tracking expenses, budgets, grocery price changes, and repeated purchases without connecting a bank account.

> 🚧 **Status:** In active development

## Features

- Expense CRUD
- SQLite local database
- FastAPI REST API
- Input validation
- Local-first financial data

## Planned

- React dashboard
- Track Monthly budgets
- Receipt scanning
- Grocery item tracking
- Track Price history
- Track Unit-price comparison
- Repeated purchase detection
- Spending insights

## Tech Stack

- React + Vite
- Python + FastAPI
- SQLAlchemy
- Pydantic
- SQLite
